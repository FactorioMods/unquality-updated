# Unquality: Updated

Provides startup switches for removing quality levels, modules, technologies, tips and achievements. Each switch controls its corresponding prototype group.

This continuation updates the original quality-removal behavior for Factorio 2.1 and retains the existing setting names.

Requires Factorio 2.1.24 or newer. Removing a group changes which quality content is available to the loaded game. Leave the optional feature-flag check disabled when using the standard Quality or Space Age expansion configuration.
